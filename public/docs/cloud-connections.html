Seed Cloud Open Clouds

Cloud connections

How Seed Cloud connects to your existing cloud accounts, where your files live, and how you stay in control.

1 How connections work

Seed Cloud never creates cloud accounts for you. You sign in with a cloud account you already own, approve the connection once, and Seed Cloud records that the account is connected.

  1. 1Choose a cloud provider.
  2. 2Click Connect.
  3. 3Sign in directly on the provider’s website.
  4. 4Review and approve the requested permissions.
  5. 5You return to Seed Cloud.
  6. 6The cloud shows as Connected.

Seed Cloud stores metadata about the connection (account name, email, storage totals). It does not copy your files into its own storage. Files stay where they are.

2 How OAuth works (in plain language)

Seed Cloud uses the same “Sign in with …” system (OAuth) that websites use for social logins. Instead of asking for your cloud password, Seed Cloud sends you to the provider, the provider verifies who you are, and the provider hands Seed Cloud a limited-use access token.

  • ✓Seed Cloud never sees or stores your cloud password.
  • ✓Authentication happens entirely on the provider’s website.
  • ✓The token lets Seed Cloud act only within the permissions you approve.
  • ✓You can disconnect at any time, and the token is removed.

4 How to connect pCloud

  1. 1Open Clouds.
  2. 2Find pCloud.
  3. 3Click Connect pCloud.
  4. 4You’ll be taken to pCloud’s sign-in page.
  5. 5Sign in with your existing pCloud account.
  6. 6Review the permissions pCloud shows you.
  7. 7Approve the connection.
  8. 8You’ll return to Seed Cloud.
  9. 9pCloud shows as Connected with your real storage usage.

If pCloud is marked “not configured on this server”, the server hasn’t been given the pCloud app credentials yet. The connection is never faked — Seed Cloud waits until the credentials are set.

5 How to disconnect

  1. 1Open Clouds.
  2. 2On the connected account, click Disconnect.
  3. 3Confirm in the dialog.

Disconnecting removes Seed Cloud’s access token for that account and unlinks it. Your files remain in the cloud provider untouched. You can connect the same account again later.

6 Where do my files live?

Files always stay in the cloud provider where you uploaded them. Seed Cloud stores only metadata about them (name, size, provider, location). It never copies the actual file bytes into its own storage.

7 Security & privacy

  • ✓Seed Cloud never asks for or stores your cloud password.
  • ✓You authenticate directly on the provider’s website.
  • ✓Provider access tokens are kept server-side and never sent to the browser.
  • ✓Tokens are encrypted at rest where a server key is configured.
  • ✓Each connection belongs to exactly one Seed Cloud account; you can’t see anyone else’s.
  • ✓Disconnecting removes the token and stops access without deleting your files.
